Welcome to Miscift! 🚀

What is it? Miscift is a 100% free, ad-free, client-side file conversion tool. We built this because we were tired of sketchy online converters that upload your personal files to remote servers, inject watermarks, or hide behind paywalls.

How does it work? By leveraging WebAssembly, Miscift processes your files locally on your own hardware, right inside the browser sandbox. Your data never leaves your device.

We need your help! This project thrives on community feedback. If you find a bug, want to request a new format, or want to contribute to the codebase, feel free to open an Issue or submit a Pull Request.

⭐️ If you like the project, please consider giving it a star to help others find a safe way to convert their files!
